# 자료 출처와 권리 안내

- `assets/NanumGothic-Bold.ttf`: Google Fonts 저장소의 Nanum Gothic Bold. 글꼴 라이선스는 `assets/NanumGothic-OFL.txt`에 포함되어 있습니다.
- `assets/forest_background_v2.png`, `assets/tool_icons/`: 전시물 제작 과정에서 생성한 이미지입니다.
- `maps/`: 프로젝트에서 사용하던 가공 지형·미리보기·경사 자료입니다. 지도 생성 도구에는 OpenTopography 링크가 기록되어 있으나, 각 실제 지형 자료의 원본 데이터셋·취득 일자·개별 이용 조건은 현재 파일만으로 확정되지 않았습니다.
- 캘리포니아 기상 CSV는 기존 프로젝트 자료입니다. 정확한 원본 제공처와 가공 과정은 별도 확인이 필요합니다.

글꼴 라이선스가 지도나 다른 자산에 적용되는 것은 아닙니다. 프로젝트 전체의 재사용 라이선스는 아직 지정하지 않았으며, 공개 저장소라는 사실만으로 모든 자료의 자유로운 재배포를 허용하는 것은 아닙니다.
