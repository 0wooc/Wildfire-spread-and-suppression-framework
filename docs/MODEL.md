# 모델과 버전 구분

지형을 셀로 나누고 낙엽·줄기 연소 상태와 열량을 갱신합니다. 인접 셀로의 열 전달에는 풍향·풍속·경사 가중치가 적용되며, 습도는 낙엽의 점화 임계값에 영향을 줍니다. 전달 열량은 별도 누적 배열에 모아 틱 계산 후 반영합니다.

노트북 풀버전은 환경 설정과 진압 전략을 실험하는 인터페이스입니다. 안드로이드 앱은 Java로 구현한 별도 실행 프로그램이며, `verification`에 모델 참조 검사와 기기용 검사 코드가 있습니다.

전시물은 비교 체험과 게임의 설정을 분리합니다. 비교에는 불암산 74×67 격자를 사용하고, 바람 비교의 습도는 양쪽 25%, 습도 비교는 70%와 0%입니다. 비교 풍향은 남동 → 남서 → 북 순서로 반복합니다. 게임은 캘리포니아 격자와 기상 자료를 사용하며, 화면에는 지도 일부를 확대해 표시합니다. 비교 배속과 게임 배속은 서로 다릅니다.

물의 냉각량, 젖은 셀의 확산 억제, 진압 수단의 쿨다운은 전시 체험 난이도를 위한 설정입니다. 현실의 장비 성능을 그대로 나타내는 값으로 해석하지 않습니다.
